# unm-nmc-burstprop

Research code for burst-dependent local learning in spiking networks, replicating
Stuck et al. 2025. Built on [PyTorch](https://pytorch.org) and
[Norse](https://github.com/norse/norse).

## Running on Windows

> **AI DISCLOSURE:** this section was generated by Claude Opus 5.

These steps assume a clean Windows 10/11 machine with no Python tooling installed.
Run everything in **PowerShell** (not `cmd.exe`).

### 1. Install Git

`uv` fetches Norse straight from GitHub, so Git must be on `PATH`:

```powershell
winget install --id Git.Git -e
```

Close and reopen PowerShell afterwards so the updated `PATH` takes effect.

### 2. Install uv

Official instructions: <https://docs.astral.sh/uv/getting-started/installation/>

Follow that page rather than trusting the commands below blindly — before running
either one, check it against the "Standalone installer" / "winget" sections of the
official docs, which are the authoritative source and will stay current if the install
command changes.

The standalone installer:

```powershell
powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
```

Or, if you prefer a signed package from a Microsoft-run source:

```powershell
winget install --id=astral-sh.uv -e
```

Reopen PowerShell, then verify:

```powershell
uv --version
```

### 3. Clone the repository

```powershell
cd $HOME\dev
git clone <repo-url> unm-nmc-burstprop
cd unm-nmc-burstprop
```

### 4. Create the environment

`uv` reads `.python-version` and installs Python 3.12 for you — no separate Python
install is needed:

```powershell
uv sync
```

This creates `.venv\` in the project directory and installs all runtime and dev
dependencies (including the pinned Norse commit). Verify:

```powershell
uv run python -c "import torch, norse; print(torch.__version__, norse.__version__)"
uv run pytest tests/norse -q
```

Notes:

- `uv sync` installs the CPU build of PyTorch by default. For an NVIDIA GPU, install
  a CUDA build explicitly, e.g.
  `uv pip install torch torchvision --index-url https://download.pytorch.org/whl/cu124`
  (match the CUDA version to your driver), then confirm with
  `uv run python -c "import torch; print(torch.cuda.is_available())"`.
- If `uv sync` fails on the Norse git dependency, the usual cause is Git not being on
  `PATH` — check with `git --version`.
- Long-path errors during install are fixed by enabling long paths:
  `New-ItemProperty -Path "HKLM:\SYSTEM\CurrentControlSet\Control\FileSystem" -Name LongPathsEnabled -Value 1 -PropertyType DWORD -Force`
  (run PowerShell as Administrator).

### 5. Run commands

Prefix everything with `uv run` — there is no need to activate the virtual
environment manually:

```powershell
uv run unm-nmc-burstprop
uv run pytest
uv run ruff check .
```

To activate the environment anyway: `.\.venv\Scripts\Activate.ps1`. If PowerShell
blocks the script, run
`Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser` first.

### 6. Set up Jupyter notebooks

JupyterLab and `ipykernel` are already installed by `uv sync`. Register the project
environment as a named kernel so notebooks can find it:

```powershell
uv run python -m ipykernel install --user --name unm-nmc-burstprop --display-name "Python (unm-nmc-burstprop)"
```

Then launch JupyterLab:

```powershell
uv run jupyter lab
```

It opens in your browser; if it doesn't, copy the `http://localhost:8888/lab?token=...`
URL from the terminal. Open a notebook under `src\unm_nmc_burstprop\` (e.g.
`mnist_classifiers.ipynb`) and select the **Python (unm-nmc-burstprop)** kernel from
the kernel picker in the top right.

For VS Code instead of JupyterLab: install the Python and Jupyter extensions, open the
repo folder, open a `.ipynb`, click the kernel selector, and pick the interpreter at
`.venv\Scripts\python.exe`.

To add a package, use `uv add <pkg>` (or `uv add --dev <pkg>`) rather than `pip
install`, so `pyproject.toml` and `uv.lock` stay in sync. Restart the notebook kernel
afterwards.
