# AGENTS.md

Research code for burst-dependent local learning in spiking networks. The current target is replicating
Stuck et al. 2025 (`docs/papers/stuck2025.pdf`). Built on PyTorch + [Norse](https://github.com/norse/norse).

## Environment

- Python 3.12, managed with `uv`: use `uv run python ...`, `uv run pytest`, `uv add <pkg>`.
- Norse is pinned to a git commit (`pyproject.toml` → `[tool.uv.sources]`), newer than the last PyPI release.
  Don't assume that remembered Norse APIs match it.

## Norse
